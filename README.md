#

Com essa proposta, espera-se criar um ambiente favorável para empresas disponibilizarem informações sobre a manipulação dos dados pessoais de maneira prática e simplificada sem comprometer segredos comerciais e, ao mesmo tempo, proporcionar uma ferramenta prática para titulares dos dados buscarem e consultarem essas informações sem a necessidade de vasculhar, de forma individual, políticas de privacidade e segurança ou procurar em mecanismos escondidos dentro das aplicações.
